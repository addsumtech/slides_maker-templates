# slides.addsum.top — slide-maker template library

The bilingual website for [slide-maker](https://github.com/addsumtech/slides_maker), served by GitHub Pages at <https://slides.addsum.top>.

The home page introduces the workflow with a video, followed by 30 template styles. Each style has two palettes, seven page previews and a copyable prompt. The library data and media live in `languages/` and are exported from the main repository's style registry.

After the template library come twelve example decks (`#examples`), each in English and Chinese. Templates set the look; the example decks show what a finished deck contains, such as charts, tables, timelines and diagrams. Each one can be flipped through in `viewer.html` or downloaded as a `.pptx`. Their files are in `templates/decks/`, their list is in `decks.js`, and their cover images are in `docs/assets/screenshots/`.

The skill, agents, scripts and installation instructions live in the [main repository](https://github.com/addsumtech/slides_maker).
