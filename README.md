# slides.addsum.top — slide-maker template library

The bilingual website for [slide-maker](https://github.com/addsumtech/slides_maker), served by GitHub Pages at <https://slides.addsum.top>.

The home page introduces the workflow with a video, followed by 30 template styles. Each style has two palettes, seven page previews and a copyable prompt. The library data and media live in `languages/` and are exported from the main repository's style registry.

The skill, agents, scripts and installation instructions live in the [main repository](https://github.com/addsumtech/slides_maker). Existing example-deck files and `viewer.html` remain available for previously shared links.
